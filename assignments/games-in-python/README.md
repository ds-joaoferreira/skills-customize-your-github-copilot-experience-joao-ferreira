
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Praticar manipulação de strings, estruturas de repetição e tomada de decisão em Python ao criar um jogo clássico de adivinhação.

## 📝 Tarefas

### 🛠️ Criar a lógica do jogo

#### Descrição
Escreva um jogo da Forca em Python em que o usuário tenta adivinhar letras de uma palavra secreta antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória de uma lista predefinida.
- Exibir o estado atual da palavra com letras reveladas e espaços para as letras ainda não descobertas.
- Aceitar palpites de letras do usuário e validar a entrada.
- Registrar as letras erradas e controlar o número de tentativas restantes.
- Evitar que o usuário repita letras já escolhidas.

### 🛠️ Finalizar a partida com feedback ao jogador

#### Descrição
Complete a experiência do jogo com mensagens de progresso, vitória e derrota para deixar o fluxo do programa claro e interativo.

#### Requisitos
O programa concluído deve:

- Exibir uma mensagem de vitória quando a palavra for completamente adivinhada.
- Exibir uma mensagem de derrota quando o número de tentativas acabar.
- Mostrar o resultado final da palavra e o estado da partida ao término.
- Permitir que o jogo seja jogado de forma clara e intuitiva no terminal.
